About Us

Built by creators, for creators.

Flixty is a free, open-source social media creator studio that enables individuals and teams to publish to X (Twitter), LinkedIn, Facebook, Instagram, TikTok, and YouTube simultaneously — with built-in AI content generation, scheduling, and live streaming.

We built Flixty because we got tired of paying $99/month for features that should be free. Every major social media tool charges per seat, per platform, and per feature — pricing out the independent creators who need these tools most.

Flixty tears down that wall. Every feature is free. Every platform is included. No upsells, no limits, no lock-in. Deploy it on your own server and own your tooling entirely.

Powered by Anthropic Claude for AI content generation — the same model behind Claude.ai — Flixty gives you enterprise-grade AI without the enterprise price tag.

Everything you need to know before you start.

Flixty is a free, open-source social media creator studio that lets you write once and publish to X (Twitter), LinkedIn, Facebook, Instagram, TikTok, and YouTube simultaneously. It includes AI-assisted content generation powered by Anthropic Claude, post scheduling with a calendar view, live streaming to YouTube and Facebook, real-time platform previews, and audience targeting — all self-hosted with no monthly fees.
Unlike Buffer and Hootsuite, Flixty is completely free and open-source under the MIT license. You self-host it on your own server — no subscription fees, no per-seat pricing, no vendor lock-in. Flixty also includes built-in AI content generation powered by Anthropic Claude, which most paid tools charge extra for. Because you host it yourself, your data never leaves your infrastructure.
Yes. Flixty is MIT-licensed and free to use, modify, and self-host. You only pay for server hosting (typically $5–$20/month on any cloud provider) and optional API costs for Anthropic Claude if you use AI features. No hidden fees, no trial periods, no premium tiers.
Flixty supports X (Twitter), LinkedIn, Facebook, Instagram, TikTok, and YouTube. Each platform has a native OAuth integration with platform-specific content formatting, character limits, and media requirements handled automatically.
Yes. Flixty integrates with the Anthropic Claude API to generate platform-optimized content. You can generate a new post from a topic, rewrite existing content adapted for a different platform's tone and character limits, and get AI-suggested hashtags — all from inside the compose window.
Yes. Flixty creates YouTube and Facebook Live broadcasts and provides RTMP server credentials and stream keys for OBS, Streamlabs, or any RTMP-compatible software. Note: TikTok and Instagram Live do not currently offer public streaming APIs, so those platforms are not supported for live streaming.
Clone the GitHub repository, run npm install, copy .env.example to .env and fill in your API credentials, then run npm start. Full setup takes about 15 minutes. Flixty deploys on NexusAI, any VPS, Railway, Render, or Docker.
